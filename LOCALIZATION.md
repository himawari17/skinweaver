# Русские подписи

Названия в `data/catalog.json` находятся в поле `ru`. Поле `name`, пути,
шаблоны файлов и ключи `skin.ini` не переводятся: от них зависит работа скинов.
В английском интерфейсе используется исходное `name`; в русском его можно
посмотреть в подсказке. Поиск понимает русские и исходные названия, включая
вложенные группы и имена файлов.

| Термин | Подпись |
| --- | --- |
| Skin mixer | Собрать скин |
| Default skin | Стандартный скин |
| Custom selection | Разные источники |
| Cursor head | Основной курсор |
| Cursor trail | След курсора |
| Approach circle | Кольцо приближения |
| Hit judgements | Оценки попаданий |
| Combo burst | Эффект серии комбо |
| Normal / Soft / Drum | Набор Normal / Soft / Drum |
| Normal / Clap / Finish / Whistle | Основной удар / Хлопок / Тарелка / Свист |
| Instafade | Круги исчезают сразу (instafade) |

Названия режимов, модов, персонажей и раскладки `1K`–`9K` сохраняют привычное
написание osu!. Подписи параметров `skin.ini` описывают назначение; оригинальный
ключ доступен в подсказке и поиске. Номер оценки и имя скина не переводятся.

Счётчики используют `Language::count`: русские формы для 1, 2–4 и остальных
чисел с исключением 11–14; английские формы единственного и множественного числа.
Проверки склонения и поиска находятся в `settings.rs` и `catalog.rs`.

Назначение элементов сверено с официальной документацией:
[Interface](https://osu.ppy.sh/wiki/en/Skinning/Interface),
[osu!](https://osu.ppy.sh/wiki/en/Skinning/osu!),
[Sounds](https://osu.ppy.sh/wiki/en/Skinning/Sounds),
[skin.ini](https://osu.ppy.sh/wiki/en/Skinning/skin.ini).
Низкоуровневые диагностические сообщения библиотек и системные диалоги могут
сохранять английский текст; они не проходят машинный перевод.

## Голос интерфейса

С версии 4.1 интерфейс обращается к игроку на «ты»: коротко, тепло, без
канцелярита. Кнопки начинаются с глагола («Собрать», «Применить к 2 скинам»),
ошибка говорит, что случилось и что сделать. Восклицательных знаков в ошибках нет.
